# Architecture ADRs (cross-cutting)

Questa directory raccoglie gli ADR che **attraversano più domini** del codebase
(`commerce/*` × `access/*` × webhook reliability × DB schema) e che quindi non
trovano posto naturale nei singoli file di `docs/adr/`.

Naming convention: prefisso numerico progressivo (001, 002, ...) per
ordinamento. Stessa struttura di `docs/adr/YYYY-titolo.md` (Status / Context /
Decision / Consequences) per coerenza con il vecchio archivio.
